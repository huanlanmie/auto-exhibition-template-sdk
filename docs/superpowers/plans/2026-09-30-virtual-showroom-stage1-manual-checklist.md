## 手测前置条件

- 使用交付说明对应的开发/验证环境，已按说明应用必要的增量业务表、菜单、私有存储、精确公开路由及运行源配置。
- 准备本人管理账号 A、无管理权限账号 B，以及可用于验证非本人归属的账号/展厅。
- 准备第一阶段交付的基础房间 GLB、完整 OBJ＋MTL＋贴图包；也可使用自己的模型，并记录尺寸与单位。
- 选择一个已有已发布的纯内容模板实例和一个带可观察交互的模板实例；记录所选实例版本。
- 准备电脑浏览器、无痕窗口/第二标签页，以及一部手机。公开链接与后台编辑地址应分别提供。
- 若某项依赖的环境或样本尚未准备，将该项记为“未执行＋原因”，不视为功能通过或失败。

## 用例

- [ ] **M01 登录、操作权限与归属**（P1-01/P1-08）：匿名打开公开链接可参观；匿名打开编辑地址进入登录；账号 B 或其他 owner 无法读取/修改本人草稿。公开内容不随登录账号改变。
- [ ] **M02 模型导入与尺度**（P1-03/P1-04）：导入 GLB、glTF 资源包、完整 OBJ 包；确认单位与已知尺寸，检查材质、方向和对象。缺少贴图给出明确报告；缺少必需 buffer/几何阻断；导入整个建筑不叠加默认 demo 房间。
- [ ] **M03 显示器编辑与持久化**（P1-04）：新增显示器，改变位置/旋转/宽高，复制、撤销/重做，保存并重开。复制对象编号不同，尺寸/朝向正确，原有绑定不丢失。
- [ ] **M04 入口、视点与碰撞**（P1-04）：设置入口、视点、墙体碰撞，进入参观模式，移动到门洞和墙边；可通过门洞，不能穿越已配置墙体。入口落入碰撞时有校验提示。
- [ ] **M05 内容绑定与相对资源**（P1-02/P1-05/P1-06/P1-08）：绑定已有实例，检查封面/比例，点击放大模板；文字、图片、视频、config/valueMap 和 JS/CSS 均正常。操作一个该模板已声明的函数，关闭后恢复原位置/视角。
- [ ] **M06 两访客/标签页隔离**（P1-05/P1-06）：两个浏览器会话/标签页打开同一展厅和模板，分别选择内容或播放位置；互不改变。关闭重开后旧消息不影响新实例；线上不会调用实体网关或本地 Bridge 网络。
- [ ] **M07 草稿与发布冲突**（P1-01/P1-04/P1-07）：两个编辑页打开同一草稿，先保存一个，再保存旧版本；后者提示冲突并保留修改。修改已校验草稿后使用旧校验结果发布，应拒绝并要求重新校验。
- [ ] **M08 发布、更新、旧会话、回滚与下架**（P1-07/P1-08）：发布后打开公开链接，再修改草稿，公开版保持原内容；线下实例更新仅出现提示。预览并重新发布后，新会话使用新版、原会话资源仍对应旧版；回滚恢复完整空间和模板。下架后新访问显示未开放，不显示草稿或要求登录。
- [ ] **M09 资源与匿名边界**（P1-01/P1-02/P1-08）：尝试访问非本人草稿/任务，修改公开资源路径或 revision，均不能得到未授权内容。原 CAD/ZIP 下载入口不公开。公开请求和 iframe 不携带管理员 token；伪造用户/内部来源头不能取得管理权限。
- [ ] **M10 异常导入与失败发布**（P1-03/P1-07）：提交损坏、缺依赖或当前未启用格式，检查错误说明/兼容导出指导；取消任务后迟到结果不应用。转换或发布失败后，当前线上版本与模板保持可用。
- [ ] **M11 手机与资源释放**（P1-06/P1-09）：手机触控/视点/展项列表可用；模板保持比例，退出控件在 iframe 外可点击。反复打开/关闭模板、进入/退出展厅，音频、计时器或输入不残留，页面不持续明显变慢。
- [ ] **M12 原有功能兼容**（P1-05/P1-09）：查看原后台入口、商城/官网入口与未配置 browser runtime 的原模板；正常加载和本地 Bridge 注册行为保持原模式。对线下设备仅观察，线上访客操作不触发新实体控制命令。
